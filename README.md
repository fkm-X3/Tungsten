# Tungsten

Use Zig 0.16.0 for this project

# Are there even any projects using Tungsten:
Yes, the in-house lang project [W](https://github.com/fkm-X3/W) uses Tungsten 

# Is tungsten even a good alternative to LLVM:
Short anser, No. As it lacks major optermization and the compiling targets that LLVM has. This is being worked on by the soul maintainer (and anyone brave enough to install zig 0.16 and create a PR) so one day it will be a worthy competitor to LLVM
